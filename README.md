# DWOR PLAY :) Jigsaw

A separate team jigsaw game. Anyone with the link can play. No accounts.

## Run locally
    npm install
    npm start
Open http://localhost:3000

## Put it online for free (Render.com)
1. Upload this folder to a NEW GitHub repository (for example `dwor-jigsaw`).
2. On render.com: New > Web Service > connect that repository.
3. Build command: `npm install`   Start command: `npm start`   Plan: Free.

## How to play
Host: open the link > Host a new game > choose the number of pieces, upload a picture for each team, set the minutes per team > Create game > share the team link.
Players: open the team link, type a name, tap Join, choose a team.
Teams play one at a time. The fastest finisher wins.
